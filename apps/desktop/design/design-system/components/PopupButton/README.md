# PopupButton

A compact pop-up button showing the current choice; opens a `Menu`.

- The Tone3000 model picker: "A2 · Feather". `marked` adds a blue dot when the person overrode the automatic pick.
- `tone="warn"` when there is nothing valid to pick ("No allowed model"); its menu explains and links to Change Allowed Variants….
- `open` shows the focus ring while its menu is open.
