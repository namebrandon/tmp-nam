# Banner

An inline message with an icon, optional bold title, body text, small action buttons and an optional Dismiss.

- `note` (blue ground): changes that apply later. Every size or gain change shows "Applies the next time you select this capture on the unit."
- `warn`: partial results and missing prerequisites. `error`: something failed or the unit dropped. `ok`: a completed result worth confirming. `info`: neutral guidance on a plain ground.
- Title states the outcome ("2 of 3 captures added"); body says what's affected and what to do. Actions are the next steps ("Send Again", "Remove It").
- Results of a long operation appear as a banner at the top of the page, never as a modal.
