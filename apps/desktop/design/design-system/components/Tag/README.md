# Tag

A small label for a fact about a row: architecture, sample rate, source, or a file problem.

- `arch` (outlined, mono): A2 shows how many sizes the container holds (`A2 · 2` in tables, `A2 · 3 sizes` in the inspector). A1 shows the single size the file is, when known (`A1 · Feather`), else just `A1`. The size is known for captures installed from Tone3000.
- `neutral`: sample rate, file size, "Bookmark".
- `accent`: "Yours", "New".
- `ok`: "On unit". `warn`: "Not registered". `danger`: "File missing", "Didn't load".
- Warning and danger tags appear only when something needs action, and the inspector explains what to do.
