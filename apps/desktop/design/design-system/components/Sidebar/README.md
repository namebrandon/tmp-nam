# Sidebar

The window's source list: traffic lights, the three sections, Settings, the running-operation card and the unit's status.

- Sections: Captures (with count), Tone3000, SD Card; Settings at the bottom.
- `unit` is always shown: connected, looking, missing (not connected) or busy (engine restarting). There is no Connect button anywhere.
- `activity` shows a long operation on every page ("Sending captures · 2 of 3"). Navigation stays enabled while it runs.
- `compact` (64 px, icons only, unit as a dot) below 820 px window width.
