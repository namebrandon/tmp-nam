# Checkbox

A native checkbox in the accent colour, with an optional label.

- Allowed variants are checkboxes grouped under A2 and A1.
- In the Tone3000 table, a row's checkbox selects it for install; a tone with no allowed model gets a disabled checkbox and a warn pop-up explaining why.
- Without a visible label, pass `aria-label` ("Select Plexi Super Lead 1968").
